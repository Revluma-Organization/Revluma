# Shopify data access capability register — discovery in progress

2026-11-05; GraphQL version examined `2026-10`, deployment version unknown. This is a living starting register, **not exhaustive**. Shopify access is conditional on app distribution, current API schema, grants, protected data, merchant/staff permissions, plan and approval. Specific field-level requirements, deletion and historical constraints must be verified per version before implementation. Shopify sources: [scopes](https://shopify.dev/docs/api/usage/access-scopes), [Admin GraphQL](https://shopify.dev/docs/api/admin-graphql/latest), [bulk](https://shopify.dev/docs/api/usage/bulk-operations/queries), [privacy](https://shopify.dev/docs/apps/build/compliance/privacy-law-compliance), [analytics](https://shopify.dev/docs/api/shopifyql).

| Resource / fields / relationships | Official mechanism and authorization | Existing Revluma path; status | Backfill, update and validation next step |
|---|---|---|---|
| Shop identity, currency, timezone, settings | Admin GraphQL `shop`; exact fields/scopes verify individually | UNKNOWN / NOT VERIFIED; `stores` has domain/owner, complete settings flow needs audit | Compare source fields and store metadata; review permitted webhook topics. |
| Products, variants, inventory quantities | GraphQL `products`, `variants`, inventory; `read_products`, other inventory/location scopes per field | PARTIALLY AVAILABLE: live `shopifyInventoryObservation`; not a certified persistent catalog | root and variant pagination; compare product/variant sets and location balances; supported product/inventory topics + reconciliation. |

| Customers, consent, orders | GraphQL `customers` / `orders`, `read_customers` and protected customer data rules | PARTIALLY AVAILABLE: `syncCustomers`, `customers`; no completeness certificate | Page and reconcile; minimize PII; verify consent timestamps and authorized access. |

| Collections, metafields/metaobjects, content, pages/blogs | GraphQL Admin field-specific access; content/metaobject scopes vary | UNKNOWN / NOT VERIFIED | Schema/permissions, source relationships and historical behavior per field. |

| Markets, currencies, shipping, taxes, B2B, subscriptions | Relevant GraphQL APIs and scopes; some protected, app-specific or conditional | UNKNOWN / NOT VERIFIED | Research exact per-field scope, ownership and approval before adding. |

| Staff, organization, personal account, billing, installed apps | Separate official interfaces and per-field limitations | UNKNOWN / NOT VERIFIED; store token does not imply account-wide access | Identify exact official interface and consent; mark inaccessible when substantiated. |

| ShopifyQL reports | GraphQL `shopifyqlQuery`, `read_reports` and applicable restrictions | UNKNOWN / NOT VERIFIED | Verify grant, dataset availability, plan, semantics and rate/row limits; distinguish from internal metrics. |
| Bulk operations | Admin GraphQL async query jobs; scope same as source and supported tokens | NOT YET VERIFIED | Design tenant-safe bounded JSONL retrieval, completion, expiry and partial failure handling. |
| Webhooks | Shopify subscriptions, HTTPS HMAC / delivery IDs | PARTIALLY AVAILABLE: registration and delivery code; operational health UNKNOWN | Verify exact topics, raw-body HMAC, duplicates, ordering and reconciliation in production. |

A number in a merchant-facing answer must be a *recorded claim* with an epistemic grade *earned from the evidence* — never a label the model decides to print. Implementation: `python/src/intelligence/epistemics.py` (keystone) + `Backend/src/services/revEpistemics.js` (Node mirror; parity enforced by the Python-generated golden fixture `revEpistemics.golden.json`, 46 cases + set + rollup, regenerated via `python/scripts/gen_epistemic_golden.py` — the Task 203 pattern).

## Retained-path decision

The new investigation entry points and the legacy `/orchestrate` path overlap in request tracing and chat persistence but have different image and response contracts. This work instruments both paths; it does not delete or redirect the legacy path without proving it unused and establishing behavior parity. The synchronous Node chat handler and streaming handler also maintain separate persistence/error paths, so both receive metrics rather than assuming one is dead.
